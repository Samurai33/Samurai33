## How I engineer

- **Security before spectacle** — authentication, authorization, isolation and sensitive-data handling are architectural concerns.
- **AI assists; humans remain accountable** — uncertain output stays explicit, reviewable and correctable.
- **Evidence over claims** — tests, CI, docs, hashes and known limitations carry the story.
- **Domain context matters** — aviation, pentesting and infrastructure have different failure models.
- **Production is a gate, not a vibe** — a working demo is not a production-ready system.
